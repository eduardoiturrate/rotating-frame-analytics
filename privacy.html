Privacy Policy: Rotating Frame analytics

Last updated: 2026-10-25

"Rotating Frame analytics" is a private desktop tool used by one person, the owner of the TikTok account @rotatingframe, to read the statistics of that same account. It is not offered to the public and has no other users.

What the tool accesses

When the owner signs in with TikTok and approves access, the tool reads, through TikTok's official API:

  • basic profile information of the owner's own account (name and account ID);
  • the account's totals: followers, following, likes and number of videos;
  • for each of the owner's own videos: its title, date, duration, and its numbers of views, likes, comments and shares.

It does not read anyone else's account, messages, contacts or private data, and it cannot post, edit or delete anything.

How the data is used

The numbers are used only to write a private weekly report that helps the owner decide which educational science videos to make next.

Storage and sharing

  • The data is stored on the owner's own computer. It is not uploaded to any server run by the tool.
  • The sign-in token is stored only on that computer, in the owner's user folder.
  • The data is not sold, shared or disclosed to anyone. The weekly report is for the owner.
  • A summary of the report may be processed by an AI assistant (Claude, by Anthropic) running on the owner's behalf, to help write the report. Only account-level and video-level counts are included, never anything about other people.

Retention and deletion

Data stays on the owner's computer until the owner deletes it. The owner can revoke the tool's access at any time in TikTok under Settings and privacy, Security and permissions, Apps and websites, and can delete the saved token and data files from the computer.

Children

The tool is not directed at children and collects no data about anyone other than the owner.
